# Cheat Menu System

Enhance your FiveM experience with this versatile cheat menu system.

## Features

- Multiple cheat options including god mode, infinite ammo, super jump, and more
- Easy-to-use menu system
- Customizable key binding

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the latest release from the [releases page](https://github.com/EnderDevelopment/cheat-menu-system/releases)
2. Extract the files into your FiveM server's resources folder
3. Import the `database.sql` file into your MySQL database
4. Add `start cheat-menu-system` to your server.cfg file

## Usage

1. Press the configured key (default: F10) to open the cheat menu
2. Select a cheat option from the menu

## Configuration

The configuration is done in the `config.lua` file. You can customize the key binding, menu title, and subtitle, as well as the available cheat options.
